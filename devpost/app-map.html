📌 What Chronos Does & How It Works

Chronos is a dual-phase forensic intelligence tool designed to parse messy multi-channel communications (emails, WhatsApp, Teams, PDFs) into a coherent, verifiable audit trail:

  • Phase 1 (Verification & Gap Detection): Audits files for temporal breaks or missing external references before running full forensic extraction.
  • Phase 2 (Dual-Panel Forensic Dashboard): Extracts a chronological timeline with actor filtering pills, classifies root-cause bottlenecks by severity, and offers actionable next steps.

🔄 The Execution Flow

🗺️ Reference Code Tour (3 Core Anchors)

  1. The Ingestion & UI State Controller: src/main.js
    Handles file drag-and-drop, sample dataset fetching, user input combination, reasoning log animation, and dual-panel rendering.
  2. The AI Engine & JSON Schemas: src/services/geminiService.js
    Controls the prompt design, response schemas, token limits (8192 max tokens), and error handling for gemini-2.5-flash. Also provides intelligent offline fallback when no API key is provided.
  3. The Forensic Theme & Print Engine: src/style.css
    Manages dynamic CSS variables (:root[data-theme="light"]), dark-mode forensic styling, actor filter pills, and custom @media print rules for executive PDF export.

🛠️ To Change This, Start Here

  • To add a new LLM provider (OpenAI, Claude, Ollama): Open src/services/geminiService.js and replace or abstract the fetch() endpoint to point to an OpenAI-compatible endpoint. The JSON schema remains identical.
  • To customize the dispute sample case: Edit the raw files in public/sample_case/ (email_thread.txt, teams_chat.txt, legal_request.eml).
  • To change the timeline display format: Modify renderTimeline() in src/main.js.
  • To tweak the printable PDF report: Edit the @media print block in src/style.css.

💡 A Practice to Reuse: Noise Filtering for Large Documents

The Problem Encountered: When ingesting a 15,000-line conversational log (e.g. WhatsApp export), an unconstrained LLM prompt attempts to extract every single trivial exchange ("ok", "ciao"), leading to request timeouts or truncated JSON.

The Solution Pattern: Explicitly instruct the model to synthesize between 10–25 critical turning points, discard informal chit-chat, and enforce a strict JSON schema with high output token allocation. This turns an unreadable flood of data into high-signal intelligence in seconds.
